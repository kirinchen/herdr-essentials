# herdr-essentials

日常用得到的 Herdr App mod(herdr-app 0.1.16 起)。先 private,穩定後轉 public 並加 GitHub topic `herdr-mod`。

| mod | 做什麼 | 狀態 |
|---|---|---|
| `k-tabs` | 內建 `tabs` 的 clone。**tab 列列的是你開過的 session,不跟著 Space / 機器換**(像 VS Code 的編輯器分頁):看過哪個 tab 它就加到列上(放在上一個的右邊),換到別的 Space 它還在;列上有不只一個 Space 的 tab 時,名字後面用小字標 Space 名(顏色跟 tab 名字一樣,不另外變淡),滑鼠停著看「機器 · Space」。點 tab 直接跳過去(跨 Space、跨機器),滾輪在列上的 tab 之間輪流,拖曳只改列上的順序(不動 Space 裡的順序)。tab 的 ×(或在任何一個 tab 上按中鍵)= 從列上拿掉並收起(`tab.settle`),程式繼續跑,之後從側欄點它就回到列上;× 在正在顯示的 tab 上一直看得到,其他 tab 滑鼠移上去才出現(每個 tab 都留了它的位置,所以不會跳動),不用先點過去就能關;關的是正在顯示的那個時,先換到右邊(沒有就左邊)那個,列上只剩一個時沒有 ×。**tab 的右鍵選單**(照 IntelliJ 的編輯器分頁,`mods/k-tabs/menu.js`):Close(同 ×)、Close Other Tabs(只留這個,並換到它)、Close All Tabs(畫面一定要顯示一個,所以正在顯示的那個留著,其他都收)—— 三個都是從列上拿掉並收起,程式繼續跑;下面是 Rename、New tab,最後的 **End tab** 才是真的結束程式(內建選單的 Close,`tab.close`)。清單每個 profile 各自記,重開 App 還在;第一次用時從目前 Space 的 tab 開始。`ctrl-tab` 等內建的 `tab.next` / `tab.prev` 仍只在目前 Space 的 tab 之間換。**單行 / 多行**:Settings → Look 最下面「Tabs on several lines」,關(預設)= 一行、放不下就左右捲;開 = 放不下就換行,tab 列自己長高到剛好放得下(視窗變寬、tab 變少會縮回來)。原本在 tab 列右邊的 Attach / Paste shot / Files / Changes 搬到下方狀態列(`k-status`),tab 列右邊只剩「+」和視窗按鈕。邏輯在 `mods/k-tabs/open.js`(`tests/k-tabs-open.test.js`) | Linux 測試環境驗過 |
| `k-spaces` | 內建 `spaces` 的 clone:點 Space 列(跟 VS Code 檔案總管一樣)同時選它、展開/收起它所有 tab(tab 的名字跟 Agents 列一致:別的 mod 用 `k-agents.rows` 取了名的,例如 kirin-tide 的「卡號-標題」,就顯示那個名字;有給 `tag` 的,名字後面也顯示同一個小標籤,例如卡的狀態),名字前的箭頭標示開合,收起時右邊數字=收起幾個;點 tab 叫回;🗑,或再點一次正在顯示的那列(框起來)後按 Del,才真的關(`tab.close`)。Space 列名字後的「+」:在那個 Space 開新 tab —— Terminal 或 agent(清單同內建 tab 列的 +,問那台機器裝了哪些),右上 YOLO 開關(或按 Y)讓 agent 不問權限啟動(Claude Code / Antigravity `--dangerously-skip-permissions`、Codex `--dangerously-bypass-approvals-and-sandbox`、Gemini `--yolo`;沒有對應參數的照常啟動並標「no YOLO flag」),開關會記住。點 Claude Code、Codex 或 Antigravity(Gemini 的 `agy`)時,如果它在這個 Space 的資料夾有過 session(讀那台機器上的紀錄,最新 12 個;`claude -p` / `codex exec` / `agy -p` 這種無頭跑的不列),先列出來讓你選一個接著做(標題或最後一句話 + 多久前),最下面是 New;沒有、或讀不到,就直接開新的。Claude Code 讀 `~/.claude/projects/`、用 `claude --resume <id>`;Codex 讀 `~/.codex/sessions/`、用 `codex resume <id>`;Antigravity 讀 `~/.gemini/antigravity-cli/conversation_summaries.db`、用 `agy --conversation <id>`。Codex 和 Antigravity 的清單要那台機器有 `node`(Antigravity 要 Node 23.4 以上,讀 SQLite)。其他 agent(Gemini CLI、Pi…)照舊直接開。邏輯在 `mods/k-spaces/sessions.js`(`tests/k-spaces-sessions.test.js`)。同一個選單的 **Chat**:跟這個 Space 的 agent 一對一對話(k-chat 的一般對話,紀錄存在那個 Space 的 `doc/chat/`;只限本機的 Space)。機器列的「+」(Spaces 標題右邊的「+」現在也是同一個選單,不再直接開空的 Space):最下面有 **Open a folder…** —— 不用打路徑,本機跳系統的選資料夾視窗,選了就把那個資料夾開成 Space(已經有那個資料夾的 Space 就切過去);別台機器則打開選單裡的資料夾瀏覽器,逐層點進去後按「Open a space here」。上面是那台的 GitHub repo 清單,點了就開 Space(沒 clone 過就先 clone 到 repo 資料夾);repo 資料夾按 Choose 改 —— 本機跳系統選資料夾視窗,遠端機器(例如從 laptop 看 back)則在選單裡列出那台的資料夾逐層點進去,可「Use as repo folder」或「Open a space here」。右鍵:Space 列(Rename、worktree、**Copy name**、**Copy path**、**MCP & Skills**、**Hide space**、Close)、展開的 tab 列(**Copy path**、**Copy address**、Rename、New tab、Close)、機器標頭(**Agents**、**Hide / Unhide**)。**Agents**:那台機器裝了哪些 agent,選一個看正在跑幾個(working / blocked / idle)、今天開過幾個 session(Claude Code、Codex),MCP server 分 user scope 與 machine scope(管理員設的 `managed-mcp.json`)、skills、plugins / extensions(Claude Code、Codex、Gemini、Antigravity 認得設定檔位置)。**MCP & Skills**:那個 Space 資料夾自己帶的(project scope):`.mcp.json`、`~/.claude.json` 裡這個資料夾的 local scope、`.claude/skills` / `commands` / `agents`、`.codex/config.toml`、`.agents/skills`、`.gemini/settings.json`、CLAUDE.md / AGENTS.md / GEMINI.md。都是唯讀,在那台機器跑一次 sh(Windows 是 PowerShell)讀檔。隱藏只影響這個視窗(每個 profile 各自記);被隱藏的機器,它的 agent 也不會出現在 `k-agents` 的 Agents 列,Spaces 標題旁的眼睛顯示藏了幾個,點一下半透明列出來好 Unhide(見 `doc/ADR/0001-profile-machine-binding.md`)。**Select Opened**(Spaces 標題右邊的定位鈕,照 IntelliJ 的 Select Opened File):把正在顯示的 session 所在的 Space 找出來 —— 機器收著就展開、Space 的 tab 清單展開、被隱藏就顯示、清單捲到它;旁邊的 **Collapse All** 把每個 Space 的 tab 清單都收起來(機器不收) | Linux 測試環境驗過 |
| `k-tabs` 的 Attach | 下方狀態列右邊的「📎 Attach」(按鈕畫在 `k-status`,做事的是 `k-tabs`;也可以綁快捷鍵 `k-tabs.attach`):系統選檔視窗(Linux zenity/kdialog、Windows PowerShell、macOS osascript)→ 路徑加引號貼進目前的 terminal,不按 Enter;遠端機器先 `hc put` 過去。借用剪貼簿後會還原原本的文字 | Linux 測試環境驗過(Claude Code 收到 `[Image #1]`) |
| `k-tabs` 的 Paste shot | 剪貼簿裡有圖片時,下方狀態列多一顆「🖼 Paste shot」(指令 `k-tabs.paste-shot`):把圖存成暫存 PNG,再像 Attach 一樣把路徑貼進 terminal(Claude Code 會變成圖片),之後把圖放回剪貼簿。補 Herdr 在 Windows 上 Ctrl+V 只貼文字的缺口。偵測靠 Windows PowerShell / Linux `xclip`(Wayland `wl-paste`)/ macOS `osascript`,沒有這些工具就不會出現。按下後約 2–4 秒剪貼簿暫時是路徑文字,圖放回去時會蓋掉這段時間複製的東西 | Linux 測試環境 + Windows laptop 驗過 |
| `k-agents` | 內建 `agents` 的 clone:側欄 Agents 列(含子 agent)右鍵 →「Copy address」,把 terminal 位址複製到剪貼簿,給 `hc send` 等指令用。別台機器的是 `back/t8`;這台的會帶上「對面那台叫這台的名字」(例:在 laptop 複製到 `laptop/t8`,貼給 back 上的 agent 可直接用;在本機自己用要拿掉前綴)。沒連別台、或對面不認得這台時是 `t8`。別的 mod 可以替某一列取名、加一個小標籤:`setShared("k-agents.rows", { "t8": { "name": "名字", "tag": "DOING", "color": "working" } })`(鍵是 terminal 位址,`color` 是主題色名),沒給的照舊;多個 mod 一起用時,每列加 `by: "<mod 名>"`,只增刪自己的列、別人的原樣留著。每列的 icon 換成**模型**的(Opus 寶石、Sonnet 羽毛、Haiku 葉子、Fable 書;Codex 程式碼、mini 閃電、其他 GPT 星星),**強度**用底色:low 沒有、medium 淡、high 深、xhigh / max 加外框;滑鼠停在 icon 上看「模型 · 強度」。資料:Claude Code 由 `tools/statusline/herdr-statusline.sh`(`./install.sh` 會在 `~/.claude/settings.json` 沒有 statusLine 時加上,要 node)寫成 terminal 標籤 `herdr.model` / `herdr.effort`;Codex 從指令列的 `-m` / `-c model_reasoning_effort=` 讀(沒帶就照舊顯示程式 icon)。Agents 標題也有同樣的 **Select Opened** 定位鈕:展開正在顯示的 agent 所在的群組(和它的上層 agent),清單捲到那一列;正在顯示的 tab 沒有 agent 時跳通知 | Linux 測試環境驗過 |
| `k-chrome` 的來回導覽 | 照 Eclipse 的三個快捷鍵,在看過的 session(一個 pane:terminal 或 mod pane)之間來回:`alt-left` 回到上一個看的、`alt-right` 回到下一個看的、`ctrl-q` 回到最後輸入的。紀錄跟瀏覽器的上一頁 / 下一頁一樣:往回之後自己換到別處,「往後」那段就丟掉;已經關掉的自動跳過;最多記 50 筆,只在記憶體(重開 App、換版面就重來)。「最後輸入」認的是**正在看的那個 agent 剛開始 working**(= 你剛送出一句話);core 沒有按鍵時間可讀,所以一般 shell 裡打字不算,還沒輸入過時按了會跳一則通知。`./install.sh` 把三個鍵加進 `keys.json` 的 `global`:`alt-left` / `alt-right` 原本是內建預設的 `pane.go:left` / `right` 才換掉(`alt-h` / `alt-l` 還是切 pane),綁了別的就不動、只提醒;`ctrl-q` 從此不會送進 terminal 裡的程式。指令是 `k-chrome.back` / `k-chrome.forward` / `k-chrome.last-input`,要換鍵在 Settings → Keys 改;邏輯在 `mods/k-chrome/nav.js`(`tests/k-chrome-nav.test.js`) | Linux 測試環境驗過(真的按鍵) |
| 快速前往(`ctrl-shift-t`) | 照 Eclipse 的 Ctrl+Shift+T:`install.sh` 把 `ctrl-shift-t` 從內建預設的 `tab.new` 改綁到內建的 `picker`(`mod.open:picker`,原本就在 `ctrl-shift-k`)。按下去直接打字過濾 tab / Space / agent 名字,↑↓ 選,Enter 跳過去(跨 Space),Esc 離開。開新 tab 改用 tab 列或 Space 列的「+」。已經把 `ctrl-shift-t` 綁到別的指令的不會動 | Linux 測試環境驗過 |
| `k-status` | 內建 `workspace-status`(terminal 下方那條狀態列)的 clone:右邊多了原本在 tab 列的 Attach、Paste shot(剪貼簿有圖才出現)、Files、Changes,把 tab 列的位置讓給 tab。Attach / Paste shot 按下去是送指令給 `k-tabs`(程式和剪貼簿偵測都在那邊),所以版面裡要有 `k-tabs` 才有作用;Files / Changes 跟原本一樣開合右側面板,每個 Space 各自記(也是 `k-tabs` 在記) | Linux 測試環境驗過 |
| `k-pane` | 內建 `pane`(每個 terminal 上方的標頭)的 clone。別的 mod 可以往標頭放一段:`shared("k-pane.chips")` = `{ <mod 名>: { <terminal 位址>: { label, text, tone, tag, color, tip, url } } }`,每個 mod 只寫自己那一格,多個 mod 可以並存;`tone` / `color` 是主題色名,有 `url`(只收 http / https)的點了用瀏覽器開。寫的 mod 要在目前的版面裡,不在就不顯示。跟內建的差別:知道模型的 agent,左邊的程式 icon 和程式名(Claude Code、Codex)換成跟 Agents 列一樣的**模型 icon**(哪一家、哪一級,底色是強度),接著是**機器名**(別台的才有,例 `back`)和 **Space 名**(通常就是 repo),terminal 自己取的名字照樣顯示;**資料夾路徑不再寫出來**,滑鼠停在這一段上看「程式 · 模型 · 強度」和路徑。不知道模型的(一般 shell、還沒回報的 agent)顯示程式 icon 和名字。模型判斷與 icon 是 `mods/k-agents/model.js`、`m-*.svg` 的複本(mod 只能 import 自己資料夾的檔,`tests/model.test.js` 檢查兩邊一致) | Linux 測試環境驗過 |
| `k-settings` | 內建 Settings 的 clone(內建的 `frame/settings` 每次啟動會被覆蓋),左邊多 Keys、Profiles、Mods 三頁;左下角 `k-chrome` 的 Settings 列開的是它(命令面板開的仍是內建版)。`herdr-app do mod.open --name k-settings` 也行 | Windows 驗過 |
| `k-settings` 的 Keys | 快捷鍵管理頁:Settings → Keys。`keys.json` 每一條照區塊(global / terminal / layout / mod)列出,可搜尋;點快捷鍵後直接按新的組合鍵(Herdr 已在用的鍵會先被執行,這種就在旁邊的框打 `alt-1` 按 Enter),同區塊撞到別的會先問 Replace / Keep it;「Add shortcut」加任何指令(例 `mod.open:k-pick`);× 刪除;Save 寫回 `keys.json`,馬上生效。還沒有 `keys.json` 時顯示內建預設,第一次存檔整份寫出。改過 `keys.json` 後 Herdr 升級的新預設快捷鍵不會自動加入 | Linux 測試環境驗過 |
| `k-settings` 的 Profiles(原 `k-profiles`) | 多開視窗:Settings → Profiles 是 profile 管理頁。每個 profile 是一個獨立的 App home(`~/.config/herdr-app-<名字>`,和預設 home 放在同一層),有自己的版面、設定和顯示中的 Space;terminal 是同一批,因為共用同一個 core。新增時複製目前視窗的版面、mod 和設定,並建一個固定入口:Windows 開始選單「Herdr (名字)」(`.lnk` → 同資料夾的 `open-herdr.vbs`,開啟時不會閃黑窗),Linux 應用程式選單(`.desktop`);macOS 只能從管理頁開。移除只刪清單和入口,資料夾保留。加入的名字對應的資料夾已存在(被移除過的、或自己手動建的)就收編:缺的才補(版面、mod、主題逐個補),已有的檔不覆蓋;手動建的資料夾若原本是 `main` 版面,收編後要自己 `layout.switch --name k-main` 一次。清單存在 `herdr-profiles.json`(和預設 home 同一層) | Linux 測試環境驗過 |
| `k-settings` 的 Mods(原 `k-mods`) | Mod 管理頁,長得像 VS Code 的擴充功能頁:Settings → Mods。左邊搜尋框 + Installed / Marketplace 兩個分頁,右邊是選到的 mod 的詳細資料和按鈕。Installed:自己的 mod 在上(來源 `owner/repo @sha7`、`local` 或 `link`,有新版會標 update available),Herdr 內建的收在「Built-in」群組、不能刪也不能停用;k-settings 自己也不能。Marketplace:GitHub topic `herdr-mod` 的 repo(有 `gh` 就用登入身分查,沒有就匿名),搜尋、Load more 分頁。安裝 / 更新前先在右邊顯示審查:會複製什麼、程式碼會不會執行程式 / 連網 / 讀寫檔案、加哪些快捷鍵,同名就擋下;按 Confirm 才裝。Disable 把 mod 搬到 `mods-disabled/`,Enable 搬回來;被 layout 用到的(例如 k-main 的 k-tabs)會拒絕並說是哪個 layout。Windows 走 PowerShell(未在 Windows 實測)。改自 [jacksonpires/herdr-app-mod-manager](https://github.com/jacksonpires/herdr-app-mod-manager)(MIT,見 `THIRD-PARTY-NOTICES.md`) | Linux 測試環境驗過 |
| `k-files` | 內建 `files`(右側 Files 面板)的 clone:`.md` / `.markdown` 檔顯示成排版後的樣子(標題、清單、表格、程式碼、連結),右上「Source」切回原始文字、「Preview」切回來 | Linux 測試環境驗過 |
| `k-pick` | 給 agent 指位置用(像 web 的 DevPick):左上角 Herdr 標題列的準心圖示(`k-chrome`,在搜尋左邊;或 `herdr-app do mod.open --name k-pick`)開一層透明覆蓋,滑鼠框出游標下的版面區塊,點一下複製定位器(layout / block / mod / 檔案 / 座標)加一張標了紅點的視窗截圖(`.k-pick/` 在 App home),貼給 agent 就知道是哪裡。對話框也認得(從 `herdr-app status` 知道開了哪個,定位器變成 `overlay=… | kind=dialog | mod=…`;k-settings 會回報自己的大小所以框得準,其他對話框照 mod.json 的大小估,估不出位置的會註明並附上底下的區塊)。**對話框開著時要用快捷鍵開 k-pick**:點標題列的準心會先把對話框關掉。快捷鍵 `ctrl-f12`:`./install.sh` 會幫你加進 `keys.json` 的 `global`(已有 `ctrl-f12` 綁別的就不動、只提醒;改過 `keys.json` 後 Herdr 升級的新預設快捷鍵就不會自動加入)。點一下或按 Space 都能選。**k-float 的桌面浮動視窗**(k-note、Inbox…)不在 Herdr 視窗裡,這層蓋不到;k-pick 開著時,每個浮動視窗的頁面自己進入選取:游標下的元素加外框,點一下複製 `float=<視窗 id> | selector=… | tag=… | text=… | at=(x,y) in element (…) of W×H | window=W×H`(只有文字,沒有截圖),k-pick 跟著關掉;在浮動視窗裡按 `Ctrl+F12` 也能單獨進入,Esc 離開 | Windows 驗過 |

## 安裝

```sh
git clone https://github.com/kirinchen/herdr-essentials.git
cd herdr-essentials
./install.sh                                  # App home 的 mods/k-* 以 symlink 指到這個 repo,並用你的 main.json 做一份 k-main(換成 k-tabs / k-spaces / k-chrome / k-agents / k-files / k-pane / k-status)
herdr-app do layout.switch --name k-main      # 換過去;回原樣:--name main(或 ctrl-alt-shift-escape)
```

- **symlink 模式(預設)**:App home 直接用 repo 裡的 `mods/`,改完直接 `git commit` / `push`;其他機器 `git pull` 就同步,不必重跑。Linux 上存檔即熱重載;**Windows 上透過 symlink 改檔不會觸發熱重載**,要切一次版面才會重新載入:`herdr-app do layout.switch --name main` 再 `--name k-main`(切到同一個版面沒用)。新開的 overlay / 對話框(例如 k-settings、k-pick)每次打開都讀新檔,不受影響。
- 手動在 App home 建連結時用 `./install.sh`,別直接 `ln -s`:Git Bash 預設的 `ln -s` 會默默變成複製,App 就一直跑舊版。
- **複製模式**:`./install.sh --copy`;之後有改動要重跑才會更新。Windows 沒開 symlink 權限(開發人員模式)時,`./install.sh` 會自己偵測到並改用複製模式,印一行提示。
- `k-main.json` 是從本機的 `main.json` 產生的,放在 App home,不在 repo;已存在就不重做,只補新版的換法(目前是 `workspace-chrome` → `k-chrome`、`agents` → `k-agents`、`files` → `k-files`、`pane` → `k-pane`、`workspace-status` → `k-status`,Profiles / Mods 收在 Settings 裡,底部維持 69px;舊版加高過的 97px / 125px 會縮回);要整份重做先刪掉。
- App 會在每個 mod 目錄自動寫入 `gpui-kit.d.ts`、`jsconfig.json`,已在 `.gitignore`。

herdr-app 本身沒有同步 mod 的功能,每台機器都要 clone + `./install.sh` 一次。
內建 mod / layout 每次啟動會被 Herdr 覆蓋,所以一律用 `k-` 前綴的複本。以 herdr-app 0.1.16 的內建版為底。

## k-chat plugin(Claude Code)

讓 Claude Code 的 session 開討論、邀人、替你發言。plugin 就是 `tools/k-chat/`(主持程式 + skill + 指令),這個 repo 同時是它的 marketplace:

```
/plugin install k-chat --marketplace kirinchen/herdr-essentials
```

| 指令 | 做什麼 |
|---|---|
| `/k-chat:new <主題> —— <開場> [成員…]` | 建檔、邀成員,在 herdr-core 背景主持(`hc run --keep`),並在 Herdr App 加一個對話 tab |
| `/k-chat:say [主題] <話>` | 替你發言(`@成員`、`/stop`、`/end` 一樣有效);主持程式沒在跑就接著開 |
| `/k-chat:invite [主題] <repo 或資料夾>` | 中途加人(別台機器、帶入某個 session 的對話) |
| `/k-chat:status [主題]` | 哪幾場、第幾輪、誰在發言、最後說了什麼(唯讀) |

需要 Node 18+ 與 `claude`;用 `start`、別台成員要有 herdr-core(`hc`)。沒有 Herdr App 也能用,紀錄一樣在 `doc/chat/`。
